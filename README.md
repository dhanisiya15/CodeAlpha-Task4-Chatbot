# CodeAlpha Task 4 - Basic Chatbot

## Objective
To build a simple rule-based chatbot using Python.

## Features
- Responds to greetings
- Answers "How are you?"
- Tells its name
- Responds to thanks
- Exits when the user types "bye"

## Concepts Used
- if-elif statements
- Functions
- while loop
- input/output

## Technologies Used
- Python

## How to Run

Run the following command in the terminal:

```bash
python chatbot.py
